# Data provenance

Do **not** commit raw UNSW-NB15 or CIC-IDS2017 datasets, any private packet captures, or derived row-level traffic. Place small dataset manifests (hashes, paths, providers, licenses, schema, class counts, split hashes, deduplication policies) under `data/manifests/`.

The Kaggle dataset input path and official source URL will be recorded only after they are verified.
